# botID 🤖

بوت تيليجرام مستقل يستقبل Telegram ID أو @username ويوجه المستخدم إلى خدمات البحث عن القنوات والمجموعات العامة.

## الوضع الحالي

هذه نسخة أولية قابلة للتشغيل، لكنها **ليست أداة استخراج عضويات تلقائية**. Telegram Bot API لا يتيح للبوت معرفة كل القروبات التي ينتمي إليها حساب عشوائي من الـID فقط. لا يوجد تكامل API موثق ضمن هذا المشروع مع TelegramDB، لذلك يفتح البوت خدمة البحث الخارجية بدل ادعاء جلب النتائج داخليًا.

## تشغيله على جهازك

1. أنشئ بوتًا عبر @BotFather.
2. انسخ التوكن واحتفظ به سرًا.
3. ثبّت Python 3.10 أو أحدث.
4. شغّل: `pip install -r requirements.txt`
5. اضبط متغير البيئة BOT_TOKEN ثم شغّل `python bot.py`.

Windows PowerShell:

```powershell
$env:BOT_TOKEN="ضع_التوكن_هنا"
python bot.py
```

Linux/macOS:

```bash
export BOT_TOKEN="ضع_التوكن_هنا"
python bot.py
```

## النشر

المشروع يحتوي Dockerfile وrender.yaml. عند النشر، أضف BOT_TOKEN كمتغير سري في إعدادات الخدمة. لا تضع التوكن داخل الكود أو GitHub.

## GitHub Actions

ملف .github/workflows/check.yml يفحص صياغة Python عند كل push أو pull request. هذا اختبار بناء فقط ولا يثبت أن البوت متصل بتيليجرام.

## البحث الخارجي

- https://www.tgdb.org/bot
- https://t.me/tgdb_search_bot

قد تتطلب بعض ميزات البحث رصيدًا أو تكون محدودة، والنتائج تعتمد على قاعدة بيانات الخدمة. لا يمكن ضمان كشف كل القروبات، خصوصًا الخاصة أو غير المفهرسة.

## الأمان

- لا ترسل كلمة مرور حساب تيليجرام أو رمز الدخول أو رمز التحقق إلى البوت.
- احتفظ بـ BOT_TOKEN سرًا.
- هذا المشروع غير تابع لتيليجرام أو TelegramDB.

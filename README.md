# botID 🤖

بوت تيليجرام يبحث في عدة فهارس ويب للعثور على صفحات القروبات والقنوات العامة. إذا تعذّر مصدر، يحاول مصادر أخرى.

## الأوامر

- `/search كلمة` — البحث عن روابط Telegram العامة.
- `/group كلمة` — البحث عن مجموعات عامة.
- `/channel كلمة` — البحث عن قنوات عامة.
- `/resolve @username` أو `/resolve ID` — البحث عن صفحات عامة مرتبطة بالمعرّف.
- `/where ID` — يبحث عن ظهور عام للمعرّف في الصفحات المفهرسة؛ لا يكشف عضويات الحساب.

يمكن أيضًا إرسال كلمة مباشرة للبوت لتبدأ البحث.

## حدود مهمة

هذه النسخة لا تستخدم TgDB ولا تتصل بقاعدة بياناته. تبحث عبر DuckDuckGo وDuckDuckGo Lite وBing، وقد تكون النتائج ناقصة أو قديمة أو محدودة بسبب الحماية ضد الطلبات الآلية. لا تستطيع كشف المجموعات الخاصة أو ضمان العثور على كل مجموعة. Telegram Bot API لا توفر قائمة المجموعات التي ينتمي إليها مستخدم عشوائي بمجرد معرفة ID.

الأمر `/where` ينفّذ بحثًا عامًا عن المعرّف فقط؛ لا يؤكد عضوية المستخدم في أي نتيجة، ولن يعرض البوت نتائج عضويات مخمّنة.

## الاختبارات

GitHub Actions يفحص صياغة Python ويشغّل اختبارات وحدات وهمية لا تحتاج إلى الاتصال بمحركات البحث. نجاحها يثبت منطق البرمجة المغطى بالاختبارات، وليس توافر محركات البحث أو نجاح النشر على Render.

## التشغيل محليًا

1. أنشئ بوتًا عبر @BotFather.
2. احتفظ بالتوكن سرًا.
3. ثبّت Python 3.10 أو أحدث.
4. نفّذ `pip install -r requirements.txt`.
5. اضبط متغير البيئة `BOT_TOKEN` ثم نفّذ `python bot.py`.

في Windows PowerShell:

```powershell
$env:BOT_TOKEN="ضع_التوكن_هنا"
python bot.py
```

## النشر على Render

أضف `BOT_TOKEN` كمتغير بيئة سري في إعدادات الخدمة. لا تضعه داخل الكود أو GitHub. استخدم أمر البناء `pip install -r requirements.txt` وأمر التشغيل `python bot.py`.

## الاختبارات

GitHub Actions يفحص صياغة Python. نجاح هذا الفحص لا يعني أن بحث الويب متاح دائمًا أو أن البوت اختُبر مباشرة على Telegram.
